# 健康观测审核记录

对应设计：[健康观测设计与实施计划](../07-health-observation-design.md)。H01–H04 的实施过程和检查见[前端与健康观测实施记录](../d02-execution/06-frontend-development-execution.md#58-f08h01worker-状态-rpc)。

## 1. 范围确认

原设计记录的用户确认结论如下；接口、采集、刷新和过期语义分别维护在设计第 3–6 节：

1. 采用一个只读 HTTP 接口和一个 Worker 状态 RPC，健康结果只用于观测。
2. 后端默认每轮结束后等待 5 秒再探测，单项预算 1 秒；过期阈值固定派生为 `2 * (interval_ms + timeout_ms)`，默认 12 秒。达到阈值的观测返回 `stale`，健康页面在独立警告区展示。
3. 浏览器只获取状态、数量、时间和错误码，内部地址及原始异常留在服务端；同一前端工程增加 `/health` 页面，进入时立即获取，此后每 10 秒自动获取，也支持手动刷新，均只重新读取缓存。
4. 前端只展示指标，不生成可接纳或整体健康结论；完整实际执行能力沿用部署验收流程。
