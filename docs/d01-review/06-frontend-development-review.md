## 1. 桌面浏览器范围确认

F03 完成后，按用户决定将支持与验收范围收敛为桌面浏览器。F01–F03 的窄屏布局与检查记录保留为历史事实，不作为后续任务或交付要求。

支持与验收范围为视口宽度不小于 1024 CSS px 的桌面浏览器；移动端及更窄视口不纳入后续适配、测试或交付要求。该结论已写入前端设计和开发计划。
